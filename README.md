# Portfolio Management System

A production-ready, full-stack portfolio website with admin dashboard, built with **Flask**, **Supabase (PostgreSQL)**, and **Vanilla JavaScript**.

## 🚀 Features

### Public Portfolio
- Modern, responsive design
- Hero section with dynamic content
- About section with stats
- Dynamic skills showcase
- Dynamic project portfolio
- Experience/education timeline
- Contact form with validation
- Smooth animations
- Mobile-friendly navigation

### Admin Dashboard
- Secure JWT authentication
- Dashboard with statistics
- Profile management
- Skills CRUD operations
- Projects CRUD with images
- Experience CRUD
- Contact message management
- Protected routes

### Technical Features
- Flask REST API
- Supabase PostgreSQL database
- bcrypt password hashing
- JWT authentication
- SQL injection prevention
- XSS protection
- Responsive design
- Loading states
- Error handling

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Backend | Python, Flask |
| Database | Supabase PostgreSQL |
| Auth | JWT + bcrypt |
| Deployment | Vercel |
